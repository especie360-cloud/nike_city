# Nike City 3D

Interactive isometric 3D city prototype built with HTML, CSS, and Three.js.

## Run locally

Serve the folder with any static server, for example:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173/
```

## Controls

- Drag: rotate the city
- Mouse wheel: zoom
- Right-drag: pan
